# Качество Python-кода

## Правила

- Используй понятные имена и небольшие функции с одной ответственностью.
- Добавляй аннотации типов на публичные функции и сложные структуры данных.
- Обрабатывай только ожидаемые исключения и сохраняй контекст ошибки.
- Не смешивай преобразование данных, побочные эффекты и вычисления без необходимости.
- Перед отправкой изменения запускай форматтер, линтер, проверку типов и тесты проекта.

## Результат

Изменение считается готовым, когда автоматические проверки проходят, а сложные решения объяснены в коде или документации.
