# Тестирование

## Когда использовать

Используй этот навык при добавлении поведения, исправлении ошибки или изменении публичного контракта.

## Правила

- Тестируй наблюдаемое поведение через публичный интерфейс.
- Добавляй проверки для успешного, граничного и ошибочного сценария.
- Делай тесты детерминированными и независимыми от порядка запуска.
- Для исправления ошибки сначала зафиксируй прежний сбой регрессионным тестом.

## Результат

Тесты должны падать при возврате дефекта и проходить после изменения без ручной правки ожидаемых результатов.
