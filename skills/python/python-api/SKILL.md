# Python API

## Правила

- Разделяй транспорт, валидацию, доменную логику и доступ к данным.
- Описывай входные и выходные схемы явно.
- Возвращай единый формат ошибок и подходящие HTTP-коды.
- Не помещай бизнес-правила в обработчики запросов.
- Учитывай таймауты, повторные запросы, авторизацию и идемпотентность.

## Проверка

Проверь контракт успешного ответа, невалидный ввод, отсутствие ресурса, отказ зависимости и повторную отправку запроса.
