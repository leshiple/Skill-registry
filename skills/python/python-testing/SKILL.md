# Тестирование Python

## Правила

- Разделяй тесты доменной логики, интеграции и HTTP.
- Подменяй внешние зависимости на границе через внедрение зависимостей.
- Проверяй исключения по типу и значимым данным, а не по случайному тексту.
- Используй фикстуры для общей подготовки, но оставляй сценарий теста очевидным.
- Не скрывай сетевые вызовы и работу с базой в быстрых модульных тестах.

## Результат

Тестовый набор должен быстро показывать, какая гарантия нарушена и на каком уровне возникла проблема.
