# Состояние Vue

## Правила

- Локальное состояние оставляй локальным, если его не читают несколько независимых частей интерфейса.
- В общий store выноси только состояние, имеющее общую жизненную семантику.
- Разделяй серверные данные, состояние интерфейса и производные значения.
- Изменения состояния проводи через явные действия, а не через скрытые побочные эффекты.
- Для асинхронности определяй состояния загрузки, успеха и ошибки.

## Проверка

Проверь начальное состояние, повторный запрос, устаревшие ответы и восстановление после ошибки.
