# Доменная логика Elixir

## Правила

- Представляй доменные состояния и переходы через структуры и типы данных.
- Делай чистые функции основным местом бизнес-правил.
- Разделяй доменную логику, интеграции и процессы OTP.
- Возвращай `{:ok, value}` и `{:error, reason}` для ожидаемых исходов.
- Используй pattern matching для проверки формы данных, а не вложенные условные конструкции.

## Результат

Доменный модуль должен тестироваться без базы данных, сети и запуска внешних процессов.
